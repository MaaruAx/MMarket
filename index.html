What is MMarket

A store for your Resolve workflow

MMarket is a standalone desktop app that lets you browse and install plugins for DaVinci Resolve without ever opening a file manager. It tracks everything it installs and can uninstall it just as cleanly.

Supports community repositories — add any compatible registry URL and its plugins appear alongside the official catalog instantly.

Features

Everything you need,
nothing you don't

Unified Store
Explore every plugin type in one place. Filter by compatibility, type, or repository. Detailed project pages featuring screenshots and full changelogs.
1-Click Install
Files go exactly where Resolve expects them. MMarket tracks everything it installs and can remove it cleanly, with no leftover files.
Auto Updates
MMarket checks for plugin updates on launch. Update individual plugins or everything at once, with real-time download progress tracking.
Multi-Repo
Not limited to the official catalog. Add any community registry URL and its plugins appear instantly alongside the official ones.
Community
Share and discover presets built on top of existing plugins. Request what you need — the community delivers.
Software Support
Dedicated section for companion apps and external tools. Install and track external software the same way you would any other plugin.
