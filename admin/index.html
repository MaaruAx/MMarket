Panel de administracion del registry
Acceso al panel
Necesitas un GitHub Personal Access Token con permisos de escritura en el repo MaaruAx/MMarket.
Crea tu token en: github.com/settings/tokens/new
Permisos necesarios: repo (acceso completo al repositorio).
El token se guarda solo en tu navegador, nunca se envia a ningun servidor.
Nuevo plugin
Solo letras minusculas, numeros y guiones
Plugins dentro de la ventana configurada en "Nuevos" reciben el badge NEW en la tienda. Dejar vacio usa la fecha de hoy.
Configuracion del Registry
